# 分析データ

元Notebookは提供ファイル `data.csv_最終`（1,470行・44列）を参照しています。CSV本体はこのリポジトリには含まれていません。

東京大学GCIの最終課題として、提供された人事データを分析しました。配布元URL、原データの作成者、加工履歴、ライセンス、再配布条件は、このリポジトリに記載していません。利用条件の確認が必要です。IBMの公開HRデータに似た列がありますが、追加項目と値が異なるため、同一データとも同じ利用条件とも断定しません。

利用権限のある元の提供CSVを `data/data.csv` として配置してください。公開データによる代替は元の結果の再現になりません。提供元の条件を確認するまではCSVを再配布しないでください。データはGit管理対象外です。公開リポジトリであること自体はコード・資料・データの再利用許諾を意味しません。

再現性の確定には、配布元URL・課題名/年度・許諾条件・加工手順・CSVのハッシュ・最終モデルのコードと環境が必要です。
